# v2.0.0 — 2026-10-10

- Unified the main real-patch benchmark, matched fresh CNN controls and nominal–GPS sensitivity under one directory and README.
- Added unlabelled genuine predictor arrays and frozen outer/inner roles; independently licensed labels are attached locally with exact full-array checks.
- Added a portable training driver that calls unchanged scientific fitting functions, fingerprints inputs/source/environment, refuses changed designs in old outputs and distinguishes partial smoke runs from full completion.
- Canonical benchmark summaries use original_fresh rather than historical main-pipeline CNN predictions.
- Preserved original target-scale and conditional-gate pilot source and aggregate results as separate exploratory supplementary material.
- Replayed 1,480 neural checkpoints on the packaging CPU. All passed the reported float32 portability tolerance; 960 passed the original stricter tolerance. Saved predictions were preserved.
- Completed a fresh 15-fit smoke run across all three suites; no full new experiment was run for this release.
- Source SOC records, label-bearing exports/arrays, point-level residuals, original checkpoints and notebook outputs are excluded from the public bundle under ESDAC conditions.
- The earlier v1.1.0 DOI archives only the historical point-RF study. A new version-specific DOI must be assigned when the current bundle is published on Zenodo.
