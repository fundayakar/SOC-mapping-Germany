# SOC-mapping-Germany

Current study: **Separating neighbourhood information from spatial arrangement in soil organic carbon prediction across Germany**.

The unified v2.0.0 code, aggregate results, data-access instructions and validation records are under [reproducibility/README.md](reproducibility/README.md). This GitHub checkout contains the source/aggregate subset; the full public ZIP additionally contains the six genuine unlabelled EO predictor arrays, frozen membership CSVs and figures. The new Zenodo version-specific DOI is pending publication.

Original SOC labels must be obtained independently from ESDAC under its licence and attached locally. The earlier [v1.1.0 Zenodo record](https://doi.org/10.5281/zenodo.20480364) archives only the former point-RF study; it does not contain the current CNN/GPS experiments. Historical root scripts and data remain as prior-version material and are not the current entry point.
